MouldMaster Academy — Privacy Notice

Effective: 5 September 2026

This notice describes the current public MouldMaster Academy build. It is not a statement that the programme is externally accredited.

Learning data

The current app stores learner profile/progress information, notes, scores, weak-area review history, practical sign-off records and assessment analytics in browser/app storage on the learner's device. Assessment analytics can include question attempts, selected-answer/distractor counts, exam and scenario results and response-time measurements. The analytics stores are scoped to the active learner profile so learners sharing one browser profile do not intentionally share question-performance history.

Learning validation analytics

The Learning insights feature keeps a separate learner-scoped local event log for lesson completion, active lesson time, diagnostic and process-data practice attempts, missed reasoning-step numbers, completed-case scores and improvement across repeat attempts. It does not store learner names, email addresses, lesson-note text, free-text responses, formal assessment answers or the text of a selected practice answer. The log is capped to a bounded number of recent events and has no application-code path for network upload. If browser/app storage cannot be read or written, Learning insights displays a local storage-health warning rather than silently treating the analytics as successfully saved.

Lesson time counts only visible active time and pauses after five minutes without interaction, so a forgotten open lesson does not continue accumulating indefinitely. Retry improvement compares a repeated case's latest completed attempt with its first tracked completed attempt rather than selecting the best score seen at any point. The app also has a local instructor view that can summarise locally stored profiles using anonymous hashed storage tokens. This view is a convenience mode stored in the same browser/app data and is not login, identity verification or a security/authorization boundary; anyone who can control that local application state can switch the view mode. The optional Learning insights pilot-summary export is cohort-level aggregate data only, contains no per-profile rows or hashed learner tokens, and is disabled until at least five current local learner profiles with Learning insights storage are present. Analytics buckets that do not map to a current local profile, including orphaned buckets left by a removed or replaced profile set, are excluded from cohort counts and aggregates.

Response timing

Question response timing is measured locally from first meaningful question exposure (substantially visible or directly interacted with) and excludes time while the document is hidden. It is used only to help the learner review question difficulty/pace. MouldMaster Academy does not currently upload this timing data or other learner analytics to a central MouldMaster server.

Production health diagnostics

The app keeps a separate bounded local technical-health log so real learner-facing failures can be reproduced and prioritised. It can record coarse categories for runtime errors, unhandled promise failures, failed same-origin app assets, online/offline transitions, service-worker update state and whether the public deployment metadata is coherent. The diagnostic log does not store learner names, email addresses, notes, assessment answers, free-text error messages, raw process-data contents, full URLs/query strings or exact event timestamps in the safe report.

Production health diagnostics does not automatically upload the local log or safe report. The Support page can create a safe diagnostic snapshot only when you choose to copy it. That snapshot contains coarse browser/platform/mode information, public release/deployment identifiers and bounded technical signal categories. Review copied diagnostics before posting them to a public issue and do not add learner personal information, backups, analytics exports, assessment answers or raw process-data files.

Read Aloud

Read Aloud is learner-controlled text-to-speech. MouldMaster does not request microphone access, record audio, perform speech recognition or upload the text being read through the Read Aloud application code. It passes visible learner-facing text to the speech-synthesis service supplied by the browser or operating system. Voice availability and whether a particular device/browser voice is processed entirely on-device or uses a provider-managed service are controlled by that browser, operating system and selected voice, not by MouldMaster.

Read Aloud does not store the spoken lesson, assessment or support text in MouldMaster learner storage. It reads only content that is currently visible to the learner; hidden app content and inactive screens are excluded. Playback stops on app navigation and is paused when the app is hidden.

Local process-data files

The Process Data area can prepare a CSV that you explicitly choose from a machine, cavity-sensing, quality or auxiliary system. The current intake module reads that selected file locally in the browser/desktop session and does not intentionally upload the raw file or save the raw file into MouldMaster learner storage. By default it removes timestamps and direct/person identifiers (including operator/person fields), aliases operational identifiers such as machine, mould, cavity, material and lot values within that preparation run, keeps suitable numeric evidence signals and only retains limited quality categories. Files above the 50,000-data-row safety limit are rejected rather than silently truncated. If a predominantly numeric retained column contains malformed nonblank values, those values are omitted from the prepared output and reported by column instead of being exported as NaN.

The prepared CSV and data-dictionary files are created only when you request an export, and you choose where to save or share them. This preparation is pseudonymisation, not guaranteed anonymisation: combinations such as rare tool/material/defect patterns or proprietary part and grade information may still be sensitive. Review prepared files before sharing them and follow your organisation's confidentiality, data-retention and data-governance requirements. MouldMaster's local preparation tool is not a substitute for the controlled source record held under your site's approved process.

Backups and analytics exports

If you export a MouldMaster progress backup, the file is created on your device and you choose where to store or share it. Assessment analytics and Learning insights event logs are deliberately not included in the progress backup; the Exams screen can create a separate local assessment-analytics JSON export on request. Learning insights can separately create a cohort-level aggregate pilot-summary JSON export while the device is in local instructor view and at least five current local learner profiles with Learning insights storage are available; that export contains no per-profile records. A successful progress-backup import resets local assessment analytics and Learning insights analytics so evidence from the previous device/profile set is not attributed to the imported learner records. The imported learner records become active only after those analytics stores have been removed and that cleanup has been re-checked. If cleanup cannot be verified, the imported learner registry is not activated, staged progress writes are rolled back where possible, and the app shows a warning instead of claiming a successful clean import; some old analytics may already have been removed during a partially completed cleanup attempt. Treat any exported learner records or analytics as personal information unless you have independently verified that the particular export is anonymous enough for your intended use.

External references

Lessons and assessment debriefs may link to third-party standards, regulators, research publications and technical references. Opening those links takes you to the third party, whose own privacy practices apply.

Website hosting

The public PWA is hosted using GitHub Pages. Like normal web hosting, the hosting/network provider may process ordinary request information needed to deliver the site. MouldMaster's current application code does not intentionally transmit local learner progress, assessment analytics, Learning insights event data, local production-health diagnostics or selected raw process-data CSV contents to GitHub Pages.

Your controls

The Exams screen's Reset local analytics control removes question-performance analytics and exposure-timing analytics for the active learner. Learning insights has a separate Clear my analytics control that removes the learning-validation event log for the active local profile without deleting lesson progress, notes or assessment records. The Support page has a separate Clear local diagnostics control for production-health signals. Read Aloud runs only when the learner starts playback and can be paused or stopped from its controls. A confirmed factory reset first removes and re-checks MouldMaster-owned assessment analytics, Learning insights analytics and training extras; only after that verified cleanup does it replace the learner registry with the clean default profile. If cleanup cannot be verified, factory reset is blocked and the current learner registry remains active rather than presenting the device as clean. If that warning persists before another learner uses the same browser/app profile, use the browser/OS site-data controls to clear the MouldMaster app data. Process-data intake is session-based; close or leave the preparation screen if you do not want the selected raw file retained in the current in-memory preparation state.

Future recognised credentials or central services

If MouldMaster later introduces provider-controlled enrolment, identity verification, public credential verification or any central learner-record/analytics/process-data/diagnostics service, this notice must be updated before those services collect personal information or operational process data.

Contact

For non-sensitive privacy or technical concerns, use the public repository issue tracker: MouldMaster GitHub Issues. Do not post learner names, backups, analytics exports, raw process-data files or other personal/confidential information in a public issue. A private publisher contact method must be supplied before any future service centrally collects learner personal information or operational process data, or where a distribution/accreditation process specifically requires one.
