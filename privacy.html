MouldMaster Academy — Privacy Notice

Effective: 24 August 2026

This notice describes the current public MouldMaster Academy build. It is not a statement that the programme is externally accredited.

Learning data

The current app stores learner profile/progress information, notes, scores, weak-area review history and practical sign-off records in the browser/app storage on the learner's device. MouldMaster Academy does not currently operate a central credential or learner-record server for this data.

Backups

If you export a MouldMaster progress backup, the file is created on your device and you choose where to store or share it. Treat exported learner records as personal information.

External references

Lessons and assessment debriefs may link to third-party standards, regulators, research publications and technical references. Opening those links takes you to the third party, whose own privacy practices apply.

Website hosting

The public PWA is hosted using GitHub Pages. Like normal web hosting, the hosting/network provider may process ordinary request information needed to deliver the site. MouldMaster's current application code does not intentionally transmit local learner progress to GitHub Pages.

Future recognised credentials

If MouldMaster later introduces provider-controlled enrolment, identity verification or public credential verification, this notice must be replaced or updated before those services collect personal information.

Your controls

You can export your progress and use the app's confirmed reset controls to remove MouldMaster-owned local learning stores from the active browser profile. Browser/site-data controls may also remove locally stored data.

Contact

A legal privacy/contact email must be added by the publisher before Microsoft Store submission or externally recognised credential delivery.
