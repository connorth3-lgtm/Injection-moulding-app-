MouldMaster Academy — Privacy Notice

Effective: 2 September 2026

This notice describes the current public MouldMaster Academy build. It is not a statement that the programme is externally accredited.

Learning data

The current app stores learner profile/progress information, notes, scores, weak-area review history, practical sign-off records and assessment analytics in browser/app storage on the learner's device. Assessment analytics can include question attempts, selected-answer/distractor counts, exam and scenario results and response-time measurements. The analytics stores are scoped to the active learner profile so learners sharing one browser profile do not intentionally share question-performance history.

Learning validation analytics

The Learning insights feature keeps a separate learner-scoped local event log for lesson completion, active lesson time, diagnostic and process-data practice attempts, missed reasoning-step numbers, completed-case scores and improvement across repeat attempts. It does not store learner names, email addresses, lesson-note text, free-text responses, formal assessment answers or the text of a selected practice answer. The log is capped to a bounded number of recent events and has no application-code path for network upload.

Lesson time counts only visible active time and pauses after five minutes without interaction. Instructor mode can summarise locally stored profiles using anonymous hashed storage tokens. Optional learning-effectiveness/cohort exports contain aggregate item statistics rather than learner names, tokens, answer text, notes or event histories. Imported cohort-calibration files are rejected if they contain learner identifiers, answer text, notes, raw process rows or exact event timestamps.

Response timing

Question response timing is measured locally from first meaningful question exposure and excludes time while the document is hidden. It is used only to help review question difficulty/pace. MouldMaster Academy does not currently upload this timing data or other learner analytics to a central MouldMaster server.

Production health diagnostics

The app keeps a separate bounded local technical-health log so real learner-facing failures can be reproduced and prioritised. It can record coarse categories for runtime errors, unhandled promise failures, failed same-origin app assets, online/offline transitions, service-worker update state and whether the public deployment metadata is coherent. The safe diagnostic report does not store learner names, email addresses, notes, assessment answers, free-text error messages, raw process-data contents, full URLs/query strings or exact event timestamps.

Production health diagnostics does not automatically upload the local log or safe report. The Support page can create a safe diagnostic snapshot only when you choose to copy it.

Read Aloud

Read Aloud is learner-controlled text-to-speech. MouldMaster does not request microphone access, record audio, perform speech recognition or upload the text being read through the Read Aloud application code. It passes visible learner-facing text to the speech-synthesis service supplied by the browser or operating system.

Local process-data files and saved process workspace

The Process Data area can prepare a CSV that you explicitly choose from a machine, cavity-sensing, quality or auxiliary system. The selected raw source file is read locally and is not intentionally uploaded by MouldMaster. During preparation, direct/person identifiers and timestamps are excluded from the research/learning context, operational identifiers can be aliased, and only the required evidence fields are passed into downstream analysis.

Learner storage and process workspace storage are different scopes. Learner progress and learner analytics are scoped to the active learner profile. Prepared process datasets, derived shots, known-good baselines, case links and intervention markers that you choose to save are stored in the browser/device IndexedDB as a device/site process workspace. They are not learner-profile records. Changing the active learner does not create a new isolated process workspace and does not delete the saved process workspace.

Saved prepared datasets can remain in IndexedDB until you delete them, clear browser/app site data or use a factory reset. The app provides metadata-only process-workspace export and saved-dataset deletion controls. Metadata-only export excludes raw process rows by default. Raw source files remain under the site's own source-system/file controls unless you independently save or share a prepared export.

Process-data preparation is pseudonymisation, not guaranteed anonymisation: combinations such as rare tool/material/defect patterns or proprietary part and grade information may still be sensitive. Follow your organisation's confidentiality, retention and data-governance requirements. MouldMaster's local preparation tool is not a substitute for the controlled source record held under your site's approved process.

Desktop local storage

The desktop build stores its application data locally on the device. MouldMaster does not currently add application-level encryption at rest to learner or process-workspace storage. Device encryption, operating-system account controls, endpoint management and physical access controls therefore remain important where the workstation contains sensitive learner or operational data.

Backups and exports

Progress backups, assessment-analytics exports, anonymous learning-effectiveness exports and process-workspace metadata exports are created on your device only when requested, and you choose where to store or share them. Assessment analytics are deliberately separate from the progress backup. A successful progress-backup import resets local assessment analytics to reduce attribution of old device/profile analytics to imported learner records. Treat exported learner records or operational metadata as sensitive unless you have independently verified that the export is suitable for your intended use.

External references

Lessons and assessment debriefs may link to third-party standards, regulators, research publications and technical references. Opening those links takes you to the third party, whose own privacy practices apply.

Website hosting

The public PWA is hosted using GitHub Pages. Like normal web hosting, the hosting/network provider may process ordinary request information needed to deliver the site. MouldMaster's current application code does not intentionally transmit local learner progress, assessment analytics, Learning insights event data, local production-health diagnostics or selected raw process-data CSV contents to GitHub Pages.

Your controls

The Exams screen's Reset local analytics control removes question-performance/exposure analytics for the active learner. Learning insights has a separate Clear my analytics control for the active learner's validation event log. The Support page can clear local diagnostics. Process Data provides controls to export saved process-workspace metadata without raw rows and to delete saved prepared datasets from the device/site workspace. A confirmed factory reset removes MouldMaster-owned learner/training, analytics and local workspace stores. Browser/site-data controls may also remove locally stored data.

Future recognised credentials or central services

If MouldMaster later introduces provider-controlled enrolment, identity verification, public credential verification or any central learner-record/analytics/process-data/diagnostics service, this notice must be updated before those services collect personal information or operational process data.

Contact

For non-sensitive privacy or technical concerns, use the public repository issue tracker: MouldMaster GitHub Issues. Do not post learner names, backups, analytics exports, raw process-data files or other personal/confidential information in a public issue.
