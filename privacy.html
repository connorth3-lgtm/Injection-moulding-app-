MouldMaster Academy — Privacy Notice

Effective: 5 September 2026 · Last updated: 2 November 2026 (browser Read Aloud media notification and screen-off behavior).

This notice describes the current public MouldMaster Academy build. It is not a statement that the programme is externally accredited.

Learning data

The current app stores learner profile/progress information, notes, scores, weak-area review history, practical sign-off records and assessment analytics in browser/app storage on the learner's device. Assessment analytics can include question attempts, selected-answer/distractor counts, exam and scenario results and response-time measurements. The analytics stores are scoped to the active learner profile so learners sharing one browser profile do not intentionally share question-performance history.

Learning validation analytics

The Learning insights feature keeps a separate learner-scoped local event log for lesson completion, active lesson time, diagnostic practice attempts, missed reasoning-step numbers, completed-case scores and improvement across repeat attempts. It does not store learner names, email addresses, lesson-note text, free-text responses, formal assessment answers or the text of a selected practice answer. The log is capped to a bounded number of recent events and has no application-code path for network upload. If browser/app storage cannot be read or written, Learning insights displays a local storage-health warning rather than silently treating the analytics as successfully saved.

Lesson time counts only visible active time and pauses after five minutes without interaction, so a forgotten open lesson does not continue accumulating indefinitely. Retry improvement compares a repeated case's latest completed attempt with its first tracked completed attempt rather than selecting the best score seen at any point. The app also has a local instructor view that can summarise locally stored profiles using anonymous hashed storage tokens. This view is a convenience mode stored in the same browser/app data and is not login, identity verification or a security/authorization boundary; anyone who can control that local application state can switch the view mode. The optional Learning insights pilot-summary export is cohort-level aggregate data only, contains no per-profile rows or hashed learner tokens, and is disabled until at least five current local learner profiles with Learning insights storage are present. Analytics buckets that do not map to a current local profile, including orphaned buckets left by a removed or replaced profile set, are excluded from cohort counts and aggregates.

Response timing

Question response timing is measured locally from first meaningful question exposure (substantially visible or directly interacted with) and excludes time while the document is hidden. It is used only to help the learner review question difficulty/pace. MouldMaster Academy does not currently upload this timing data or other learner analytics to a central MouldMaster server.
