MouldMaster Academy — Privacy Notice

Effective: 24 August 2026

This notice describes the current public MouldMaster Academy build. It is not a statement that the programme is externally accredited.

Learning data

The current app stores learner profile/progress information, notes, scores, weak-area review history, practical sign-off records and assessment analytics in browser/app storage on the learner's device. Assessment analytics can include question attempts, selected-answer/distractor counts, exam and scenario results and response-time measurements. The analytics stores are scoped to the active learner profile so learners sharing one browser profile do not intentionally share question-performance history.

Response timing

Question response timing is measured locally from first meaningful question exposure (substantially visible or directly interacted with) and excludes time while the document is hidden. It is used only to help the learner review question difficulty/pace. MouldMaster Academy does not currently upload this timing data or other learner analytics to a central MouldMaster server.

Backups and analytics exports

If you export a MouldMaster progress backup, the file is created on your device and you choose where to store or share it. Assessment analytics are deliberately not included in the progress backup; the Exams screen can create a separate local analytics JSON export on request. A successful progress-backup import resets local assessment analytics to prevent old device/profile analytics from being attributed to the imported learner records. Treat any exported learner records or analytics as personal information.

External references

Lessons and assessment debriefs may link to third-party standards, regulators, research publications and technical references. Opening those links takes you to the third party, whose own privacy practices apply.

Website hosting

The public PWA is hosted using GitHub Pages. Like normal web hosting, the hosting/network provider may process ordinary request information needed to deliver the site. MouldMaster's current application code does not intentionally transmit local learner progress or assessment analytics to GitHub Pages.

Your controls

The Exams screen's Reset local analytics control removes both question-performance analytics and exposure-timing analytics for the active learner. A confirmed factory reset removes the MouldMaster-owned learner/training and assessment-analytics stores. Browser/site-data controls may also remove locally stored data.

Future recognised credentials or central services

If MouldMaster later introduces provider-controlled enrolment, identity verification, public credential verification or any central learner-record/analytics service, this notice must be updated before those services collect personal information.

Contact

For non-sensitive privacy or technical concerns, use the public repository issue tracker: MouldMaster GitHub Issues. Do not post learner names, backups, analytics exports or other personal information in a public issue. A private publisher contact method must be supplied before any future service centrally collects learner personal information or where a distribution/accreditation process specifically requires one.
