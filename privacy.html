MouldMaster Academy — Privacy Notice

Effective: 26 August 2026

This notice describes the current public MouldMaster Academy build. It is not a statement that the programme is externally accredited.

Learning data

The current app stores learner profile/progress information, notes, scores, weak-area review history, practical sign-off records and assessment analytics in browser/app storage on the learner's device. Assessment analytics can include question attempts, selected-answer/distractor counts, exam and scenario results and response-time measurements. The analytics stores are scoped to the active learner profile so learners sharing one browser profile do not intentionally share question-performance history.

Learning validation analytics

The Learning insights feature keeps a separate learner-scoped local event log for lesson completion, active lesson time, diagnostic and process-data practice attempts, missed reasoning-step numbers, completed-case scores and improvement across repeat attempts. It does not store learner names, email addresses, lesson-note text, free-text responses, formal assessment answers or the text of a selected practice answer. The log is capped to a bounded number of recent events and has no application-code path for network upload.

Lesson time counts only visible active time and pauses after five minutes without interaction, so a forgotten open lesson does not continue accumulating indefinitely. Instructor mode can summarise locally stored profiles using anonymous hashed storage tokens. The optional pilot-summary export contains aggregate metrics and anonymous profile numbers rather than names, notes, selected-answer text or event timestamps.

Response timing

Question response timing is measured locally from first meaningful question exposure (substantially visible or directly interacted with) and excludes time while the document is hidden. It is used only to help the learner review question difficulty/pace. MouldMaster Academy does not currently upload this timing data or other learner analytics to a central MouldMaster server.

Local process-data files

The Process Data area can prepare a CSV that you explicitly choose from a machine, cavity-sensing, quality or auxiliary system. The current intake module reads that selected file locally in the browser/desktop session and does not intentionally upload the raw file or save the raw file into MouldMaster learner storage. By default it removes timestamps and direct/person identifiers (including operator/person fields), aliases operational identifiers such as machine, mould, cavity, material and lot values within that preparation run, keeps suitable numeric evidence signals and only retains limited quality categories.

The prepared CSV and data-dictionary files are created only when you request an export, and you choose where to save or share them. This preparation is pseudonymisation, not guaranteed anonymisation: combinations such as rare tool/material/defect patterns or proprietary part and grade information may still be sensitive. Review prepared files before sharing them and follow your organisation's confidentiality, data-retention and data-governance requirements. MouldMaster's local preparation tool is not a substitute for the controlled source record held under your site's approved process.

Backups and analytics exports

If you export a MouldMaster progress backup, the file is created on your device and you choose where to store or share it. Assessment analytics are deliberately not included in the progress backup; the Exams screen can create a separate local analytics JSON export on request. Learning insights can separately create an anonymous aggregate pilot-summary JSON export. A successful progress-backup import resets local assessment analytics to prevent old device/profile analytics from being attributed to the imported learner records. Treat any exported learner records or analytics as personal information unless you have independently verified that the particular export is anonymous enough for your intended use.

External references

Lessons and assessment debriefs may link to third-party standards, regulators, research publications and technical references. Opening those links takes you to the third party, whose own privacy practices apply.

Website hosting

The public PWA is hosted using GitHub Pages. Like normal web hosting, the hosting/network provider may process ordinary request information needed to deliver the site. MouldMaster's current application code does not intentionally transmit local learner progress, assessment analytics, Learning insights event data or selected raw process-data CSV contents to GitHub Pages.

Your controls

The Exams screen's Reset local analytics control removes question-performance analytics and exposure-timing analytics for the active learner. Learning insights has a separate Clear my analytics control that removes the learning-validation event log for the active local profile without deleting lesson progress, notes or assessment records. A confirmed factory reset removes the MouldMaster-owned learner/training and analytics stores. Browser/site-data controls may also remove locally stored data. Process-data intake is session-based; close or leave the preparation screen if you do not want the selected raw file retained in the current in-memory preparation state.

Future recognised credentials or central services

If MouldMaster later introduces provider-controlled enrolment, identity verification, public credential verification or any central learner-record/analytics/process-data service, this notice must be updated before those services collect personal information or operational process data.

Contact

For non-sensitive privacy or technical concerns, use the public repository issue tracker: MouldMaster GitHub Issues. Do not post learner names, backups, analytics exports, raw process-data files or other personal/confidential information in a public issue. A private publisher contact method must be supplied before any future service centrally collects learner personal information or operational process data, or where a distribution/accreditation process specifically requires one.
