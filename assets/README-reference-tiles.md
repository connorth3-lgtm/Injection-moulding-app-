# Selected mockup reference image sheet

The 7 × 5 WebP atlas `mockup-reference-tiles.webp` contains 33 **direct small crops** from the owner's selected five-screen generated design. Tiles 0–8 mirror Learn categories, 9–18 the material-polymer illustrations, 19–27 Practice tiles, 28–30 Home hero, Book and practice, and 31–32 the molecule and moulded-component detail illustrations.

These are small UI reference illustrations from the composition, **not independently verified machine/product photos, chemical structures, exact-grade images or engineering measurements**. They must never act as source evidence. Material properties, manufacturing origin, suitability, processing settings and machine changes remain governed by the linked primary supplier sources and safety warnings. The app also renders its substantive book-engineering SVG diagrams under an independent expandable `Engineering diagrams and explanations` panel.

Image bytes were cropped from the supplied generated reference, reduced to 36px tiles and compressed to 6,960 bytes. Cropping preserves composition, but cannot recreate missing high-resolution photography. The atlas loads on demand with local engineering SVG fallback so governed PWA first-install static asset counts and desktop manifest parity remain unchanged.

The Home machine hero has a separate locally stored 96 × 175 WebP crop (`mockup-home-machine.webp`), taken from the same owner-selected composite without baked-in UI lettering. This avoids enlargement of a 36px atlas tile. The photo is illustrative, not a real machine identification, OEM instruction or source of operating limits.
