## Controller documentation

### Strong match

**Techmation M8M / M10M HMI Controller & Software Manual**  
https://hitechinterplas.com/assets/default/file/download/1458918147M8M%20M10M%20manual_E_010305%20%2800000002%29.pdf

The photographed HMI layout strongly matches this family. A direct 80-page Techmation PDF has been verified. It covers operation, HMI reference, I/O diagnostics/reassignment, machine diagnostics, machine-set data, DA adjustment and alarm/error indexes. The manual explicitly states that machine safety, general operation and maintenance require the machine manufacturer's manual. Treat it as the best current operator-interface reference, not as proof of the exact host controller.
