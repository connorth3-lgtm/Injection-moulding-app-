# HMD400M6 — owner-assisted OEM evidence intake checklist

Status: **request not yet sent / documents not yet received** (2026-10-08). This is a *research request*, not permission to service, wire, bypass or adjust the machine. Follow site lockout/tagout and qualified OEM service procedures.

## What to identify before asking the OEM

Keep sensitive plate/serial photographs and contact information in an authorised private site record, not this public repository.

- Machine-maker name on plate, `HMD400M6` nameplate, build date, serial and visible generation/suffix. Do **not** assume `HMD400M6-S` matches `HMD400M6`.
- Installed injection unit/screw assembly identifier and OEM revision, where available.
- HMI/controller plate part number and hardware/software versions; the Techmation M8M/M10M panel resemblance does **not** identify the underlying controller or installed I/O board.
- Original service distributor/OEM document pack number and revision/issue date, if available.
- Authorised maintenance contact and evidence of rights to share/distribute each returned document.

## Request exact matched documents (ask for title, revision, serial applicability and access rights)

1. OEM machine-specific *operation and maintenance manual*.
2. Electrical schematic/wiring pages with installed controller/terminal/I/O assignment and revision.
3. Hydraulic schematic, installed pump/valve configuration and revision.
4. OEM lubrication diagram and interval sheet for installed components.
5. OEM parts book / exploded service drawings for the exact serial and injection unit.
6. Injection-unit options/revisions, screw/barrel configuration table and as-built part numbers.

## Verification procedure before adding to the public library

For every returned document, record source/publisher, exact retrieval URL or private-access provenance, date checked, document number, revision and permitted sharing level. Compare machine model **and suffix**, as-built controller/I/O hardware and installed injection unit with the named serial. Mark unrelated Techmation hardware books and M6-S material `reference_only` until identity is proven. Distinguish verified *document identity* from independently tested *machine capability*.

If access is confidential or portal-only, list the verified access route and metadata publicly **without uploading the proprietary document**. Keep unresolved items `missing`; surface conflicting OEM variant sheets as separate source records. Do not infer safe process settings from an archived brochure.
