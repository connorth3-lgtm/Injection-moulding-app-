App does not update

For the installed PWA, connect to the internet, open MouldMaster, close it fully and reopen it. Offline content is refreshed through the service worker after a successful online check.

Windows update blocked safely

The legacy recovery launcher and the open Electron desktop are separate release lanes. If the legacy Windows updater says an update was blocked, keep the current installed recovery copy. The updater is designed to reject content that fails validation rather than replace a known-good copy.

Progress, analytics and backups

Use the app's progress export before changing browser profiles, clearing site data or moving devices. The current backup contains all local learner profiles plus each profile's scoped review/sign-off, measured-assessment, process-diagnostics, Diagnostic Learning Lab and Material Behaviour Lab progress. Import replaces the local learner registry after confirmation rather than merging profiles. Imported progress backups are validated and certificates are intentionally re-earned on the receiving device. Assessment analytics and Learning insights events are separate learner-scoped, device-local stores and are not part of the progress backup. A progress import resets both analytics histories and verifies that cleanup before the imported learner registry becomes active. If analytics cleanup cannot be verified, the import is blocked from becoming active and the app shows a warning rather than claiming a clean import; staged progress writes are rolled back where possible, although some old analytics may already have been removed. A confirmed Reset learner data clears only the active learner's progress, notes, certificates, analytics, review/sign-off, measured-assessment, process-diagnostics and lab-progress state; other local learner profiles are kept. If that cleanup warning persists before another learner uses the same browser/app profile, clear MouldMaster site/app data using the browser or operating-system controls.

Certificates

Current certificates are MouldMaster learning-completion records. They are not yet NZQA-approved qualifications, IACET CEUs, statutory authorisation or proof of machine-specific workplace competence.

Safety or technical concern

Do not use the app to override a machine safeguard, site isolation procedure, resin supplier instruction or applicable legal requirement. If you identify a potentially incorrect safety or technical item, stop relying on that item until it has been reviewed against the cited/current source.

Publisher support contact

For non-sensitive technical reports, use the learner-problem form above or the public repository issue tracker: MouldMaster GitHub Issues. Do not post learner names, exported backups or other personal information in a public issue. A private publisher contact method must be supplied before any future service centrally collects learner personal information or where a distribution/accreditation process specifically requires one.
