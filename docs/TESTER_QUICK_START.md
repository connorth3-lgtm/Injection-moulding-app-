# MouldMaster Academy — private preview tester quick start

**Non-production learning preview · web release 2026.10.09.3 · not a machine-control tool**

Thanks for helping test MouldMaster. You are reviewing the *learning experience*, not approving machine settings, certifications, qualifications, professional competence, or production procedures. The preview is not an externally validated public release.

## Before opening

- Use your own browser profile on a phone, tablet or computer, preferably on a device you can reset safely. **Do not use a shared production workstation or device containing other people's learner records.**
- Use an **invented name/pseudonym** for the local learner profile. When onboarding asks for **Your name**, enter something fictional (for example, **Trial Learner**), or use the default; no real name is required for this evaluation. Do not enter a real person's details, employer, customer, site, production part, proprietary machine settings or confidential process evidence.
- The app stores learning progress on the **device/browser**, not in a cross-device learner account. Losing site storage can lose your work. Browser private/incognito sessions may not persist progress or offline support.
- Do **not** upload actual plant CSVs or progress backups for this evaluation. Use only built-in training cases or deliberately fictional examples.
- On machinery or at work, continue to follow manufacturer instructions, approved site procedures, risk assessment, safeguarding and qualified supervision. Never implement a learning example as a production recipe.

Look for the persistent **“Non-production preview”** notice. If it is absent, the page redirects unexpectedly, or the site looks like a release-hold/error page, **stop and tell your inviter** rather than assuming this is the tested build.

## Suggested 15–20 minute route

1. **First impression:** Open the preview. Is it clear what you can do? Can you create/select a local learner profile without entering personal information?
2. **Learn:** Open a lesson, continue it, find the objective, and return to the Home view. Check that a beginner can understand the explanation and the “what to do next” cue.
3. **Book:** Find a reference relevant to a familiar defect or process question. Does it make the limits of generic advice understandable?
4. **Practice:** Try a diagnostic/scenario question. Check the question, answer feedback and explanation; do not judge quality solely by whether you guessed correctly.
5. **Mission Control:** Start a fictional mission, note evidence and try advancing stages. If you create two local learners, switch between them and check that a mission from learner A never appears for learner B.
6. **Your device:** Check text size, navigation, keyboard/touch targets and readability. If you use a screen reader, describe any difficulty—this is feedback, **not** formal assistive-technology validation.
7. **Optional offline test:** Only after a successful first online load, try reopening the **installed preview** without a connection. Do not assume all features work offline without testing.

You can stop at any time. No questionnaire or learning outcome is automatically submitted by the app.

## Report a problem safely

From the preview, open **Support → Report a learner problem**, or use the [learner-problem issue form](https://github.com/connorth3-lgtm/Injection-moulding-app-/issues/new?template=learner-problem.yml). Posting a GitHub issue may require a GitHub account. You can instead reply privately to your inviter with a **sanitised description only**.

Please include your **device and browser (approximate versions if known)**, whether you used browser/installed mode, what you were trying to do, what you expected, what happened, and numbered steps to reproduce it. If convenient, include the app release number visible in Support.

**Never put names, email addresses, contact details, exact site/customer information, raw process data, assessment answers, learner notes, screenshots containing private information, analytics exports or progress backups in a public issue.** Support's “Copy safe diagnostics” is optional; always inspect its text before sharing.

For safety-critical advice, learner privacy leakage or lost progress, stop that activity and report it promptly. **Do not publicly disclose security details or sensitive evidence**; see [SECURITY.md](../SECURITY.md) for private security reporting guidance.
