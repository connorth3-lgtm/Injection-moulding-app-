# Contextual research evidence architecture

`MM_RESEARCH_EVIDENCE` is the canonical runtime mechanism layer. Other modules consume it rather than redefining evidence rules.

Adapters translate existing surfaces into canonical research context. The UI displays mechanism evidence, weakening evidence and verification plans. Workspace/microlearning bridges reuse the same mechanism IDs. Local utilisation and gap modules store bounded categories only. Claim freshness creates review hints only and never changes evidence maturity automatically.
