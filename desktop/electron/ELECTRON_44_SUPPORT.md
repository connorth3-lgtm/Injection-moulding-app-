# Electron 44 support boundary

MouldMaster Academy uses Electron `44.3.0` for the open Windows desktop runtime.

## Supported MouldMaster desktop scope

- Windows 10/11, 64-bit only.
- The GitHub portable/NSIS validation lane is x64.
- The Microsoft Store MSIX lane packages x64 and arm64.
- Windows ia32 is not a supported MouldMaster target.
- MouldMaster does not currently publish macOS or Linux desktop packages.

This matches Electron 44's upstream platform boundary: Electron 44 no longer publishes Windows ia32 or Linux armv7l binaries, and macOS 12 is no longer supported. Those removals therefore do not drop a currently shipped MouldMaster desktop target.

## Electron 44 breaking-change review

The Electron 44 migration review covered the upstream breaking changes that can affect application code:

- renderer `clipboard` access was removed and several clipboard methods became asynchronous;
- `net.request` now enforces navigate mode for frame/document destinations;
- `select-client-certificate` may receive a null `webContents` for non-WebContents requests;
- pre-macOS-13 login-item attributes were removed;
- ANGLE is statically linked and its DLLs can no longer be replaced independently.

The current MouldMaster repository does not use `clipboard`, `net.request`, `select-client-certificate`, `setLoginItemSettings`, ia32-specific packaging logic, or custom/swapped ANGLE libraries. The desktop renderer remains sandboxed with Node integration disabled, so the clipboard renderer removal does not invalidate an existing privileged renderer path.

## Electron 44.3.0 patch review

The 44.3.0 patch release was reviewed as a patch-level runtime update within the already-approved Electron 44 platform boundary. Upstream notes include Chromium 152.0.7977.78, additional frame/origin scoping for permissions and internal IPC, File System Access lifecycle fixes, crash fixes across Windows/Linux/WebContents paths, and other maintenance fixes. MouldMaster does not rely on the affected privileged renderer APIs or unsupported architectures. The permission/frame-attribution and IPC hardening are compatible with the existing deny-by-default renderer boundary, and no supported MouldMaster OS/architecture target is added or removed by this patch update.

## Upgrade validation contract

An Electron major upgrade is mergeable only after all of the following are true on the exact final PR head:

1. `desktop/electron/package.json` pins the intended Electron version exactly.
2. `desktop/electron/package-lock.json` is regenerated by npm and `npm ci` resolves that exact runtime.
3. The stable portable/NSIS builder remains separately pinned to `electron-builder 26.16.1`; this patch update is reviewed together with Electron 44.3.0 and must remain exact-lock reproducible.
4. The isolated MSIX toolchain remains independently locked and verified.
5. Release QA and open-desktop security/integrity QA pass.
6. Mobile Browser QA passes its Chromium plus cross-browser regression matrix.
7. Open Desktop Build produces the real unsigned Windows portable package and records its SHA-256 evidence.

A green compatibility probe by itself is not enough to change the supported-platform policy; the platform boundary and upstream breaking changes must also be reviewed.
