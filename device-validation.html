MouldMaster device validation helper

This page collects only browser-visible device metadata on this device. Nothing is uploaded, transmitted, stored, or sent automatically.

Use this page on each physical device. Auto-detected values are editable because iOS/iPadOS browsers may hide the exact hardware model or OS detail. If a value says it is unavailable, replace it only with information you can verify on the device.

Android often exposes a model string. Safari commonly exposes only iPhone/iPad family, not the exact model. For production validation this must be standalone after launching the installed PWA.
